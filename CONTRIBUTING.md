# Contributing

Everyone on the team has push access. Here's how to contribute.

## Workflow

1. Create a branch from `main`
2. Add or modify your tool in the appropriate tier directory
3. Open a PR
4. Get it reviewed and merged

## Guidelines

- **One tool per directory.** Keep tools self-contained with their own README, dependencies, and tests.
- **Don't break other tools.** Shared dependencies should be discussed before introducing.
- **README is mandatory.** Every tool directory must have a README.md explaining what it does and how to use it.
- **Keep it simple.** A 20-line shell script with a clear README is better than an over-engineered framework nobody understands.

## PR expectations by tier

| Tier | Review required | Tests required |
|------|----------------|----------------|
| Sandbox | 1 approval (lightweight) | No |
| Incubating | 1 approval | Yes, some form |
| Graduated | 1 approval + broader review | Yes, comprehensive |

## Questions?

Open an issue or ask in the relevant team channel.
